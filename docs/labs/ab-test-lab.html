The eight-step A/B testing workflow

Every readout belongs to a step

The numbers below update with the data in the panel. Steps 4 and 5 happen before the experiment runs. This lab checks a finished experiment, so it reports the smallest lift these sample sizes could reliably detect. Plan the sample size itself in the Power and Sample Size Lab.

  1. Define the metric

    One primary metric, with guardrails. Here: conversion rate = conversions ÷ visitors.

  2. State H0 and H1

    Direction matters.

  3. Pick α

    Default 0.05; stricter for medical or financial decisions.

  4. Pick power 1 − β

    Industry default 0.80: an 80% chance of detecting a real lift of the planned size.

  5. Compute the required sample size

    From the MDE, α, β and baseline.

  6. Randomise; run

    Random assignment is what makes the difference causal.

  7. Compute CI, p-value

  8. Communicate

    Bottom line first, the lift with its CI, then the decision. See the verdict box under the plot.

Test statistic: pooled SE. Under H0 both groups share one rate.
p̄ = (xA + xB) / (nA + nB)
SE₀ = √( p̄(1 − p̄)(1/nA + 1/nB) )
z = (p̂B − p̂A) / SE₀
Confidence interval: unpooled SE. No assumption that the rates are equal.
SE = √( p̂A(1 − p̂A)/nA + p̂B(1 − p̂B)/nB )
(p̂B − p̂A) ± 1.96 · SE
With the current numbers

Takeaway for students. Report the CI on the difference, not separate CIs for each arm. The pooled and unpooled SEs are almost equal in most business tests, which is why the CI and the test nearly always agree. When they disagree, the result is borderline, and the consultant's answer is more traffic, not a different test.

CI for one proportion

Poll of n = 1,000 with 540 in favour: p̂ = 0.54, SE ≈ 0.0158, CI (0.509, 0.571). Entirely above 50%.

p̂ ± 1.96 · √( p̂(1 − p̂)/n )

Decision rules

Reject H0 when the statistic passes the critical value, or equivalently when p < α. The p-value is P(data at least this extreme | H0), not P(H0 | data).

Two-sided: |z| > 1.96
One-sided: z > 1.645

One group against a benchmark

Coke vs Pepsi tests one proportion against p₀ = 0.5. The SE uses p₀ because the test assumes H0 is true.

z = (p̂ − p₀) / √( p₀(1 − p₀)/n )
(0.56 − 0.5) / 0.05 = 1.2

Try this in class

  1. Load Google search. Ask the room: ship Algo 2 or not? The p-value is just under 0.05 and the CI almost touches 0. Ask for three wrong ways to read this result, then press "Simulate" and count the amber bars.
  2. Keep Google search and double both visitor counts and both conversion counts. The rates stay the same, but the CI shrinks by about 1/√2 and the verdict becomes clear.
  3. Load Coke vs Pepsi with the one-sided test. z = 1.2 is short of 1.645. Change the drinkers to 430 and successes to 241 (56%). Now the same 6-point lead is significant.
  4. Load pink vs black and switch between two-sided and one-sided. The one-sided p-value is exactly half. Then pick "B < A": the p-value is near 1, because the data point the other way.
  5. Load Karaca. With 20,000 sessions per arm the lab's CI is wider than the original example's. Ask students how many sessions that narrower interval implies (about 34,000 per arm).
