Confidence vs prediction intervals

A CI is for the mean. A PI is for the next customer.

The same samples drive both intervals below. For each sample we also draw one new observation Xnew from the population. The confidence interval aims at μ and rarely contains Xnew. The prediction interval adds the spread of a single observation, so it is about √(n + 1) times wider and traps Xnew at the stated rate.

What 95% means

The recipe, not one interval, has the 95%. Repeat the sampling many times and 95% of the intervals built this way contain μ. Any single interval either contains μ or it does not.

x̄ ± z · σ/√n (σ known)
x̄ ± tn−1 · s/√n (σ unknown)

With 10,000 replications a regression simulation found coverage 0.948. Run 10,000 here and compare.

Proportions: Wald and Wilson

The textbook interval p̂ ± z·√(p̂(1 − p̂)/n) is the Wald interval. It undercovers when n is small or p is near 0 or 1, and at p̂ = 0 it has width zero. The Wilson interval inverts the score test and stays close to the nominal level.

Wald: p̂ ± z √(p̂(1−p̂)/n)
Wilson: [p̂ + z²/2n ± z √(p̂(1−p̂)/n + z²/4n²)] / (1 + z²/n)

Patriots revisited

The Patriots won 19 of 25 coin tosses in 2014–15. p̂ = 0.76 and the 95% Wald interval is 0.76 ± 0.167 = (0.593, 0.927). The lower end is above 0.5, but the interval is enormous. With 25 tosses you cannot tell rigged from lucky.

1.96 √(0.76 · 0.24 / 25) = 0.167

The preset sets p = 0.76 and n = 25 to ask: if this really were the Patriots' rate, how often would the Wald recipe trap it?

Try this in class

  1. Draw one batch of 100 and count the red bars together. Ask: "Is this interval 95% likely to contain μ?" Then run continuously until 10,000 intervals and read the coverage.
  2. Switch to "Mean, σ unknown" with z with s at n = 5. Coverage drops to about 88%. Switch to the t interval: the bars get wider and coverage returns to 95%. Slide n up to 100 and the two methods agree.
  3. Move the confidence level from 95% to 80% and to 99%. Ask students to predict how many of the 100 bars will be red before each draw.
  4. Load the Patriots preset. The Wald recipe covers about 94% instead of 95%. Then try the rare-event preset (p = 0.03, n = 25): Wald coverage collapses to about 53%, while Wilson stays near 96%.
  5. In the CI vs PI panel, ask what fraction of new customers fall inside the CI. At n = 25 it is about 30%, which is why a CI is the wrong tool for forecasting one person.
