From a layer to a deep network

Why stacking f(Wx + b) bends the boundary

Each demo sets the sliders and starts training. The first shows the network with no hidden layer, which is logistic regression. It cannot solve XOR however long it trains. The next two fix that in different ways.

  1. One layer is a weighted sum and a bend

    A neuron computes w·x + b, a number that is constant along straight lines in the plane, and then passes it through an activation f. The output neuron uses the sigmoid σ, which turns the score into a probability. With no hidden layer this is exactly logistic regression: the boundary p̂ = 0.5 is the straight line w·x + b = 0.

  2. A straight line cannot separate XOR

    XOR puts class 1 in the top-right and bottom-left quadrants. Any line leaves at least one quadrant on the wrong side, so the best a linear model can do is about 50 to 75% accuracy. The algebra on the right shows the contradiction for the four corner points.

  3. Hidden neurons build new features

    Each hidden neuron draws its own line and bends it with f. Look at the thumbnails: in the XOR demo, the first-layer neurons are soft half-planes. The output neuron adds them with weights, and a sum of bent half-planes can carve out two quadrants. Stacking more layers composes these pieces again, which is the edges → shapes → objects idea.

  4. Training is gradient descent on the loss

    The loss is the negative log-likelihood, the same objective as logistic regression. Backpropagation applies the chain rule layer by layer to get ∇L for every weight. Each batch moves the weights a step of size η downhill. Adam rescales the step for each weight using running averages of past gradients.

class 1: ( 1, 1), (−1,−1) need w₁+w₂+b > 0, −w₁−w₂+b > 0
class 0: ( 1,−1), (−1, 1) need w₁−w₂+b < 0, −w₁+w₂+b < 0
add each pair: 2b > 0 and 2b < 0. Impossible.
The x₁·x₂ fix: one engineered feature makes XOR linear
p̂ = σ(w·x₁x₂ + b), class 1 when x₁x₂ > 0

Takeaway for students. A neural network is a stack of logistic-regression-like pieces. The hidden layers learn the features you would otherwise have to engineer by hand, such as x₁·x₂ for XOR or x₁² + x₂² for circles. The price is many more parameters, a loss surface with many valleys, and the need for held-out data to check that the fit is real.

MNIST is the same recipe

The MNIST network has 784 inputs, layers of 256 and 128 ReLU neurons, and a 10-way softmax output. It has 235,146 parameters, trained on 60,000 images. This playground has the same parts at a size you can see.

p̂ₖ = exp(sₖ) / Σⱼ exp(sⱼ) (2 classes: σ)

The learning rate is a step size

Too small and the loss creeps down for thousands of epochs. Too large and each step overshoots the valley, so the loss bounces or blows up. Good values depend on the optimizer: Adam works near 0.01 to 0.03 here, plain SGD near 0.3.

θₜ₊₁ = θₜ − η ∇L(θₜ)

Train vs test loss

training loss falls toward zero and validation loss tracks it with a small gap. With noisy data and a big network the gap widens: the network memorizes the training points. The L2 penalty shrinks weights and smooths the surface. Dropout does a similar job.

Try this in class

  1. Press "XOR, no hidden layer". Ask students to predict the best accuracy. The loss stalls near 0.69 and the shading stays nearly flat. Then press "XOR, one layer of 4 tanh" and watch the four quadrants appear within a few hundred epochs.
  2. On Circles, set hidden layers to 1 and neurons to 2. The boundary is a band or a wedge, never a closed loop. Raise neurons to 3 and press Reset: three lines are enough to enclose the center.
  3. Pick Spiral with 1 layer of 2 neurons and train for 1,000 epochs. Then use "Spiral, 3 layers × 8". Count parameters in the table each time and compare with the 235,146 of the MNIST network.
  4. Set noise to 50% on Moons, use 3 layers × 8 with learning rate 0.03, and train for 2,000 epochs. Training loss keeps falling while test loss turns up. Raise λ to 0.01 and reset: the gap closes.
  5. Switch to SGD and compare learning rates 0.03, 0.3 and 3 on Circles. Watch the loss curve: slow, smooth, and jagged. Then set batch size to 1 and to 100 at η = 0.3 and compare the noise in the curve.
