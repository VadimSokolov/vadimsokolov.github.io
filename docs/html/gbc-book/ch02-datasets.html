2  Motivating Datasets

“The purpose of computing is insight, not numbers.” — Richard Hamming

This chapter previews the datasets and test functions that serve as running examples throughout the book. We present them here so that later chapters can focus on methodology rather than data description. Table 2.1 provides a summary; the “Chapter” column indicates where each dataset is first analyzed in depth.

The datasets span heteroscedasticity, jump discontinuities, high dimensionality, scalability, active learning, likelihood-free inference, and causal estimation. Some are synthetic (allowing exact metrics against the truth), some come from real scientific applications, and some involve expensive simulators. A recurring theme is the tension between GP-based methods (calibrated uncertainty from small samples, but \(\mathcal{O}(n^3)\) cost and smoothness assumptions) and GBC (scalable, flexible, but requiring more data to learn structure that a good kernel encodes for free).

2.1 Motorcycle Crash Data

The motorcycle crash dataset (Silverman 1985) records head acceleration (\(g\)) versus time (ms) for \(n = 133\) simulated motorcycle crashes. It is the canonical benchmark for heteroscedastic regression: variance changes by roughly two orders of magnitude across the input range, from quiet pre-impact measurements to violent crash-event deceleration.

NoteDataset summary
  • Source: Silverman (1985); available in R’s MASS::mcycle
  • Size: \(n = 133\) observations, \(d = 1\) input (time after impact)
  • Response: Head acceleration (\(g\))
  • Key feature: Variance changes dramatically across the input range
  • Used in: Section 5.7 (IQN quantile fan), Chapter 7 (GBC vs. hetGP)
Show code (17 lines)
Code 
import numpy as np
import matplotlib.pyplot as plt

from gbc.data import load_motorcycle

ax.scatter(t, y_moto, s=12, alpha=0.6, color='k', zorder=3)
ax.axvspan(15, 35, alpha=0.08, color='red', label='High-variance region')
ax.set_xlabel("Time after impact (ms)")
ax.set_ylabel("Head acceleration ($g$)")

plt.show()

On this benchmark, GBC and the purpose-built heteroscedastic GP (hetGP) achieve comparable CRPS (\(\approx 12.5\)), but the motorcycle data has only 133 observations — a regime where GPs are at their best. The real advantage of GBC emerges on larger, higher-dimensional problems.

2.2 Flowers Test Functions

The Flowers benchmark suite (Flowers et al. 2026) consists of four synthetic datasets designed to test surrogate methods on response surfaces with jump discontinuities. Jump discontinuities arise whenever a physical system undergoes a regime change — a material fractures, an epidemic tips from containment to exponential growth, or a manufacturing line hits capacity. The suite isolates this challenge in controlled settings where the true boundary geometry is known exactly.

2.2.1 Phantom Function

A bivariate response surface (\(d = 2\)) with a sinusoidal jump boundary at \(\sin(x_1) = x_2\). Each regime generates the response from a different Gaussian component.

NoteDataset summary
  • Source: Flowers et al. (2026)
  • Size: \(N = 10{,}201\) on a grid; \(n_{\text{train}} \approx 9{,}000\) after 90/10 split
  • Dimension: \(d = 2\)
  • Response: Bimodal (two Gaussian components separated by jump)
  • Boundary: \(\sin(x_1) = x_2\) (sinusoidal)
  • Used in: Section 8.5 (Aug-IQN benchmark)
Show code (35 lines)
Code 
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)
n = 5000
x1 = np.random.uniform(-3, 3, n)
x2 = np.random.uniform(-3, 3, n)

regime = (x2 > np.sin(x1)).astype(int)
y = np.where(regime == 0,
             np.random.normal(2.0, 0.5, n),
             np.random.normal(8.0, 0.5, n))

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 4))

sc = ax1.scatter(x1, x2, c=y, s=2, alpha=0.5, cmap='RdYlBu_r', rasterized=True)
xg = np.linspace(-3, 3, 200)
ax1.plot(xg, np.sin(xg), 'k--', linewidth=1.5, label=r'$\sin(x_1) = x_2$')
ax1.set_xlabel("$x_1$")
ax1.set_ylabel("$x_2$")
ax1.set_title("Phantom: response surface")
ax1.legend(fontsize=8, loc='upper right')
plt.colorbar(sc, ax=ax1, label='Response')

ax2.hist(y[regime == 0], bins=40, alpha=0.6, color='steelblue',
         label='Regime 0', density=True)
ax2.hist(y[regime == 1], bins=40, alpha=0.6, color='coral',
         label='Regime 1', density=True)
ax2.set_xlabel("Response $y$")
ax2.set_ylabel("Density")
ax2.set_title("Phantom: bimodal marginal")
ax2.legend(fontsize=8)

plt.tight_layout()
plt.show()

GBC-Aug slightly outperforms MJGP on CRPS (0.009 vs. 0.010) while improving RMSE by 17% (0.044 vs. 0.053), training in ~23 seconds per replicate on GPU versus over 600 seconds for MJGP on CPU.

2.2.2 Star Function

A bivariate response (\(d = 2\)) with an angular, star-shaped partition. The boundary has sharp corners at each of five tips where the two regimes nearly touch, making boundary detection harder than Phantom.

NoteDataset summary
  • Source: Flowers et al. (2026)
  • Size: \(N = 10{,}201\); \(n_{\text{train}} \approx 9{,}000\) after 90/10 split
  • Dimension: \(d = 2\)
  • Response: Bimodal (same structure as Phantom)
  • Boundary: Star-shaped polygon with sharp corners
  • Used in: Section 8.6 (Aug-IQN benchmark)
Show code (31 lines)
Code 
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)
n = 5000
x1 = np.random.uniform(-1.5, 1.5, n)
x2 = np.random.uniform(-1.5, 1.5, n)

theta = np.arctan2(x2, x1)
r = np.sqrt(x1**2 + x2**2)
r_star = 0.4 + 0.6 * (0.5 + 0.5 * np.cos(5 * theta))
regime = (r < r_star).astype(int)

y = np.where(regime == 1,
             np.random.normal(7.0, 0.5, n),
             np.random.normal(2.0, 0.5, n))

fig, ax = plt.subplots(1, 1, figsize=(5.5, 5))
sc = ax.scatter(x1, x2, c=y, s=2, alpha=0.5, cmap='RdYlBu_r', rasterized=True)
theta_plot = np.linspace(-np.pi, np.pi, 500)
r_plot = 0.4 + 0.6 * (0.5 + 0.5 * np.cos(5 * theta_plot))
ax.plot(r_plot * np.cos(theta_plot), r_plot * np.sin(theta_plot),
        'k--', linewidth=1.5, label='Star boundary')
ax.set_xlabel("$x_1$")
ax.set_ylabel("$x_2$")
ax.set_title("Star: response surface")
ax.legend(fontsize=8)
ax.set_aspect('equal')
plt.colorbar(sc, ax=ax, label='Response', shrink=0.8)
plt.tight_layout()
plt.show()

GBC-Aug achieves CRPS = 0.013, outperforming MJGP’s 0.024 by 46% — the largest improvement in our jump-boundary comparisons.

2.2.3 AMHV Function

The AMHV (Automated Material Handling Vehicle) dataset (Kang et al. 2024) records average transport time for autonomous vehicles in a semiconductor fab. Unlike Phantom and Star, the response is not cleanly bimodal — the regime transition is gradual, making this a control case where augmentation is unnecessary and plain GBC suffices.

NoteDataset summary
  • Source: Kang et al. (2024)
  • Size: \(N = 9{,}503\), \(d = 4\)
  • Inputs: Vehicle speed, acceleration, minimum inter-vehicle distance, empty-vehicle search range
  • Response: Average transport time (seconds)
  • Key feature: Smooth regime transition (NOT a sharp binary jump)
  • Used in: Section 8.7 (plain GBC vs. MJGP)

2.2.4 Michalewicz Function

The Michalewicz function (Surjanovic and Bingham 2013) is a standard optimization test function with steep ridges and valleys: \[ f(x) = -\sum_{i=1}^{d} \sin(x_i) \sin^{2m}\!\left(\frac{i \, x_i^2}{\pi}\right), \quad x_i \in [0, \pi], \tag{2.1}\] where \(m = 10\) controls the steepness. In the Flowers suite, a \(0.5\) offset is added to the flat region, introducing a jump manifold in four-dimensional input space.

NoteDataset summary
  • Source: Surjanovic and Bingham (2013) (Virtual Library of Simulation Experiments)
  • Size: \(N = 100{,}000\) (Latin hypercube sample), \(d = 4\)
  • Key feature: Large \(n\) makes MJGP computationally infeasible (\(\geq 48\) hours)
  • Used in: Chapter 8 (scalability demonstration)

With \(n = 90{,}000\) training points, the GP’s \(\mathcal{O}(n^3)\) cost is infeasible (\(\approx 65\) GB for the covariance matrix alone). GBC trains in under 30 minutes on a single GPU, achieving CRPS = 0.031 with 91% coverage.

2.3 BGP Test Functions

The Bi-mixture Gaussian Process (BGP) test problems from Park et al. (2026) provide controlled piecewise-continuous response surfaces. A random hyperplane \(a^\top x = 0\) partitions the unit hypercube into two regions, each with an independent GP realization at different mean levels: \[ f_1 \sim \mathcal{GP}(13,\; 9\, k_{\text{SE}}), \quad f_2 \sim \mathcal{GP}(0,\; 9\, k_{\text{SE}}), \tag{2.2}\] with \(k_{\text{SE}}\) using length scale \(\ell = 0.1d\) and additive noise \(\varepsilon \sim \mathcal{N}(0, 4)\).

NoteDataset summary
  • Source: Park et al. (2026)
  • Size: \(N = 2{,}000\) per realization, \(d \in \{2, 3, 4\}\)
  • Response: Piecewise-continuous (two GP realizations with different means)
  • Partition: Random hyperplane \(a^\top x = 0\) with \(a \in \{-1, +1\}^d\)
  • Used in: Section 7.4 (GBC vs. stationary GP)
Show code (43 lines)
Code 
import numpy as np
import matplotlib.pyplot as plt
from scipy.linalg import cholesky

np.random.seed(7)
n = 800
d = 2
X = np.random.uniform(-0.5, 0.5, size=(n, d))

a = np.array([1.0, -1.0])
region = (X @ a >= 0).astype(int)

def se_kernel(X1, X2, sigma2=9.0, ls=0.2):
    diff = X1[:, np.newaxis, :] - X2[np.newaxis, :, :]
    sq_dist = np.sum(diff**2, axis=-1)
    return sigma2 * np.exp(-sq_dist / (2.0 * ls**2))

f = np.zeros(n)
for idx_set, mean_val in [(region == 1, 13.0), (region == 0, 0.0)]:
    idx = np.where(idx_set)[0]
    if len(idx) == 0:
        continue
    K = se_kernel(X[idx], X[idx]) + 1e-5 * np.eye(len(idx))
    L = cholesky(K, lower=True)
    f[idx] = L @ np.random.randn(len(idx)) + mean_val

y = f + np.random.normal(0, 2, n)

fig, ax = plt.subplots(1, 1, figsize=(5.5, 5))
sc = ax.scatter(X[:, 0], X[:, 1], c=y, s=8, alpha=0.6, cmap='RdYlBu_r',
                rasterized=True)
xb = np.linspace(-0.5, 0.5, 100)
ax.plot(xb, xb, 'k--', linewidth=1.5, label=r'$a^\top x = 0$')
ax.set_xlabel("$x_1$")
ax.set_ylabel("$x_2$")
ax.set_xlim(-0.55, 0.55)
ax.set_ylim(-0.55, 0.55)
ax.set_title("BGP realization ($d = 2$)")
ax.legend(fontsize=8)
ax.set_aspect('equal')
plt.colorbar(sc, ax=ax, label='Response', shrink=0.8)
plt.tight_layout()
plt.show()

GBC’s CRPS advantage over the stationary GP grows from 11% at \(d = 2\) to 26% at \(d = 4\), because the GP’s single global length scale becomes progressively less effective as more training data falls near the hyperplane boundary. Full results appear in Section 7.4.

2.4 Friedman 10D

The Friedman function (Friedman 1991) is a standard benchmark for high-dimensional regression: \[ f(x) = 10\sin(\pi x_1 x_2) + 20(x_3 - 0.5)^2 + 10 x_4 + 5 x_5, \quad x \in [0,1]^{10}. \tag{2.3}\]

Only five of the ten inputs are active; the remaining five are inert noise variables. The \(\sin(\pi x_1 x_2)\) term creates a non-separable interaction that separable GP kernels cannot represent faithfully.

NoteDataset summary
  • Source: Friedman (1991)
  • Size: \(n \in \{500, \ldots, 20{,}000\}\) (varies by experiment), \(d = 10\)
  • Active inputs: Only \(x_1, \ldots, x_5\); the remaining five are inert noise variables
  • Key features: Nonlinear interaction (\(\sin(\pi x_1 x_2)\)), quadratic and linear terms, inert variables
  • Noise: \(\varepsilon \sim \mathcal{N}(0, 1)\)
  • Used in: Section 7.5 (GBC vs. GP), Section 7.6 (scaling study)
Show code (27 lines)
Code 
import numpy as np
import matplotlib.pyplot as plt
from gbc.data import friedman1

n_grid = 80
x1g = np.linspace(0, 1, n_grid)
x2g = np.linspace(0, 1, n_grid)
X1, X2 = np.meshgrid(x1g, x2g)
X_grid = np.column_stack([X1.ravel(), X2.ravel(),
                          0.5 * np.ones(n_grid**2),
                          0.5 * np.ones(n_grid**2),
                          0.5 * np.ones(n_grid**2),
                          0.5 * np.ones(n_grid**2),
                          0.5 * np.ones(n_grid**2),
                          0.5 * np.ones(n_grid**2),
                          0.5 * np.ones(n_grid**2),
                          0.5 * np.ones(n_grid**2)])
Y_grid = friedman1(X_grid).reshape(n_grid, n_grid)

fig, ax = plt.subplots(1, 1, figsize=(6, 5))
cf = ax.contourf(X1, X2, Y_grid, levels=20, cmap='viridis')
ax.set_xlabel("$x_1$")
ax.set_ylabel("$x_2$")
ax.set_title("Friedman function: $f(x_1, x_2, 0.5, 0.5, 0.5, 0, \\ldots, 0)$")
plt.colorbar(cf, ax=ax, label='$f(x)$')
plt.tight_layout()
plt.show()

Even on this GP-friendly benchmark, GBC achieves 12% lower RMSE and 14% lower CRPS, because the multiplicative interaction between \(x_1\) and \(x_2\) is difficult for separable kernel functions. The GP becomes computationally infeasible beyond \(n \approx 2{,}000\) due to its \(\mathcal{O}(n^3)\) Cholesky cost; we develop this scaling comparison fully in Section 7.6.

2.5 Active Learning Benchmarks

The next three datasets are used in Chapter 9, where training points are acquired sequentially based on where the surrogate is most uncertain. They span a range from GP-favorable to GBC-favorable.

2.5.1 2D Exponential

The 2D Exponential function (Sauer, Gramacy, and Higdon 2023) is a smooth, unimodal surface: \[ f(x_1, x_2) = 10 \, x_1 \exp(-x_1^2 - x_2^2), \quad (x_1, x_2) \in [-2, 2]^2, \tag{2.4}\] with additive Gaussian noise \(\varepsilon \sim \mathcal{N}(0, 0.1^2)\). This is a control case where the GP’s smoothness prior is perfectly matched to the target. The GP-based DGP+ALC method achieves 21% lower RMSE than GBC-AL — an honest assessment of GBC’s limitations on small, smooth problems.

NoteDataset summary
  • Source: Sauer, Gramacy, and Higdon (2023)
  • Size: \(n_0 = 10\) initial points, growing to \(n = 100\) via active learning
  • Dimension: \(d = 2\)
  • Key feature: Smooth, unimodal — ideal for GP surrogates
  • Used in: Section 9.4 (active learning benchmark where GP wins)
Show code (17 lines)
Code 
import numpy as np
import matplotlib.pyplot as plt

n_grid = 80
x1g = np.linspace(-2, 2, n_grid)
x2g = np.linspace(-2, 2, n_grid)
X1, X2 = np.meshgrid(x1g, x2g)

fig, ax = plt.subplots(1, 1, figsize=(6, 5))
cf = ax.contourf(X1, X2, Y, levels=20, cmap='RdYlBu_r')
ax.set_xlabel("$x_1$")
ax.set_ylabel("$x_2$")
ax.set_title("2D Exponential: $f(x_1, x_2) = 10 x_1 \\exp(-x_1^2 - x_2^2)$")
plt.colorbar(cf, ax=ax, label='$f(x)$')
plt.tight_layout()
plt.show()

2.5.2 Rocket Booster (LGBB)

The Langley Glide-Back Booster benchmark (Pamadi et al. 2004; Gramacy 2020; Sauer, Gramacy, and Higdon 2023) models aerodynamics of a reusable NASA rocket booster. The three inputs are Mach number, angle of attack, and side-slip angle; the response is the side-force coefficient. A sharp nonlinear ridge at the sound barrier (Mach \(\approx 1\)) makes this hostile to stationary GPs.

NoteDataset summary
  • Source: Pamadi et al. (2004) (NASA); used in Gramacy (2020) and Sauer, Gramacy, and Higdon (2023)
  • Size: \(n_0 = 50\) initial points, growing to \(n = 300\) via active learning
  • Dimension: \(d = 3\) (Mach number, angle of attack, side-slip angle)
  • Response: Side-force coefficient
  • Key feature: Sharp nonlinear ridge at the sound barrier (Mach \(\approx 1\))
  • Used in: Section 9.5 (active learning benchmark where GBC dominates)

GBC-AL achieves \(2.95\times\) lower RMSE than DGP+ALC — the most dominant result in our active learning comparisons, with 90% confidence bands separating completely by \(n \approx 150\).

2.5.3 Satellite GRACE

The Satellite GRACE benchmark (Sun et al. 2019; Mehta et al. 2014; Sauer, Gramacy, and Higdon 2023) uses a Test Particle Monte Carlo (TPMC) simulator to compute drag coefficients for satellites in low-Earth orbit. The seven inputs describe thermospheric conditions; the response is the satellite drag coefficient. The surface is smooth and well-matched to GP assumptions.

NoteDataset summary
  • Source: Sun et al. (2019); TPMC simulator for GRACE satellite
  • Size: \(n_0 = 110\) initial points (including replicate pairs), growing to \(n = 500\)
  • Dimension: \(d = 7\) (atmospheric composition, velocity, temperature variables)
  • Response: Satellite drag coefficient
  • Key feature: Smooth surface, stochastic simulator (~86 seconds per evaluation)
  • Used in: Section 9.6 (active learning crossover benchmark)

This dataset reveals a crossover: GBC-AL leads in the early acquisition phase (\(n < 300\)) but the GP-based DGP+ALC overtakes GBC at larger sample sizes (\(n = 500\)). The lesson: when the total acquisition budget is small (the practically relevant regime for expensive simulators), GBC provides better accuracy; when the budget is large and the surface is smooth, the GP’s inductive bias eventually wins.

2.6 Ebola Agent-Based Model

The Ebola agent-based model (Fadikar et al. 2018) simulates disease spread through a population, producing 56-week epidemic trajectories as output. Five input parameters control transmission rate, initial infections, hospital intervention timing and efficacy, and travel reduction. The ABM has no tractable likelihood — the stochastic, agent-level interactions are far too complex for any analytical likelihood function — making it a canonical example for likelihood-free Bayesian inference.

NoteDataset summary
  • Source: Fadikar et al. (2018); RAPIDD Ebola Forecasting Challenge (Viboud et al. 2018)
  • Size: 300 parameter scenarios, 100 replicates each, 56-week trajectories
  • Dimension: \(d = 5\) input parameters
  • Response: 56-week cumulative incidence trajectory
  • Key feature: Bimodal output (epidemic vs. no epidemic), no tractable likelihood
  • Used in: Chapter 10 (posterior inference for simulator parameters)

The ABM exhibits bimodal behavior: for some parameter settings the epidemic takes off; for nearby settings it sputters and dies. This tipping-point structure produces a bimodal output distribution that no Gaussian surrogate can represent faithfully. We use GBC to learn the posterior quantile function and produce credible intervals for all five parameters, including in the bimodal regime. Details in Chapter 10.

2.7 Lake Temperature

The Falling Creek Reservoir lake temperature dataset (Holthuijzen et al. 2025) consists of \(N = 281{,}764\) records combining physics-based General Lake Model (GLM) outputs with observed water temperatures at multiple depths and forecast horizons. Six input features include day of year, depth, forecast horizon, lagged surface temperature, and the GLM ensemble mean and standard deviation.

NoteDataset summary
  • Source: Holthuijzen et al. (2025); Falling Creek Reservoir, Virginia
  • Size: \(N = 281{,}764\) (\(n_{\text{train}} = 172{,}714\), \(n_{\text{test}} = 109{,}050\))
  • Dimension: \(d = 6\) input features
  • Response: Observed water temperature (\({}^\circ\)C)
  • Key feature: High signal-to-noise ratio causes IQN failure
  • Train/test split: Temporal (before / after 2022-06-11)
  • Used in: Chapter 14 (het-MLP ensemble + conformal calibration)

This dataset illustrates a case where the IQN fails: the high signal-to-noise ratio (the physics-based simulator already captures most of the variance) causes the multiplicative \(\tau\)-embedding architecture to collapse all quantile levels to the conditional mean. The failure motivates the het-MLP ensemble with conformal calibration developed in Chapter 14.

2.8 LaLonde Wage Data

The LaLonde dataset (LaLonde 1986) evaluates the effect of the National Supported Work (NSW) job training program — a randomized experiment with known average treatment effect (ATE \(\approx\) $1,500–$2,000 in 1978 dollars), providing rare ground truth for causal inference methods.

NoteDataset summary
  • Source: LaLonde (1986); refined by Dehejia and Wahba (1999)
  • Size: \(n = 445\) (185 treated, 260 control)
  • Dimension: \(d = 8\) covariates
  • Treatment: NSW job training program (binary)
  • Response: Real earnings in 1978 (dollars)
  • Key feature: Randomized experiment with known ATE \(\approx\) $1,500–$2,000
  • Used in: Section 13.7 (causal inference benchmark)

GBC estimates not only the ATE but the quantile treatment effect (QTE) — how the treatment reshapes the entire outcome distribution. On the LaLonde data, the QTE profile reveals that the NSW program’s primary benefit is preventing the worst outcomes, with large effects at low quantiles and smaller effects at higher quantiles. We develop this approach in Section 13.7.

Exercise 2.1 Exploring the motorcycle data.

Load the motorcycle data using from gbc.data import load_motorcycle.

  1. Plot the data and visually identify the three phases (pre-impact, crash, recovery). At approximately what time does the crash event begin and end?

  2. Compute the sample standard deviation of the response in three windows: \(t < 15\) ms, \(15 \leq t \leq 35\) ms, and \(t > 35\) ms. By what factor does the variance change between the pre-impact and crash phases?

  3. Fit a simple linear regression of acceleration on time. Compute the residuals and plot their absolute values versus time. Does the residual plot confirm heteroscedasticity?

  4. Compute a rolling standard deviation using a window of 10 observations. Plot it versus time. Does it capture the three-phase structure?

Exercise 2.2 Friedman function exploration.

Generate \(n = 2{,}000\) points from the Friedman function using from gbc.data import friedman1.

  1. Compute the correlation between each of the 10 inputs and the response \(y\). Which inputs have the largest absolute correlation? Does correlation correctly identify all five active variables?

  2. The \(\sin(\pi x_1 x_2)\) interaction is invisible to univariate correlations. Compute the partial dependence of \(y\) on \((x_1, x_2)\) by averaging over the remaining inputs. Plot this as a contour map. How does it compare to Figure 2.5?

  3. Add Gaussian noise with \(\sigma = 1\) and repeat the correlation analysis. Increase \(\sigma\) from 1 to 10. At what noise level does the correlation between \(x_5\) and \(y\) become indistinguishable from zero at a 95% confidence level?

Exercise 2.3 Phantom boundary difficulty.

Generate 5,000 points from the Phantom function (two Gaussian regimes separated by \(\sin(x_1) = x_2\)).

  1. Fit a logistic regression classifier to predict the regime from \((x_1, x_2)\). Report accuracy on a held-out test set. Why does the linear decision boundary fail?

  2. Fit a \(k\)-nearest-neighbors classifier with \(k = 5\). Does it achieve higher accuracy? Where does \(k\)-NN make the most errors?

  3. Train a two-layer MLP with 128 hidden units. Report accuracy and compare the learned decision boundary to the true boundary \(\sin(x_1) = x_2\).

  4. For each classifier, compute accuracy specifically for test points within distance 0.1 of the true boundary. How does near-boundary accuracy compare to overall accuracy?

Exercise 2.4 Lake temperature structure.

  1. Why is a temporal train/test split more appropriate than a random split for this dataset? What assumption of standard cross-validation would a random split violate?

  2. The forecast horizon \(h\) ranges from 1 to 30 days. Explain why RMSE should increase with \(h\). Does this suggest a single prediction interval width is appropriate for all horizons?

  3. If the GLM were a perfect forecast, what signal-to-noise ratio would the statistical model face? Explain why this would cause a quantile regression model to collapse its quantile bands.

## Flowers Test Functions {#sec-data-flowers}

The Flowers benchmark suite [@flowers2026modular] consists of four synthetic datasets designed to test surrogate methods on response surfaces with *jump discontinuities*. Jump discontinuities arise whenever a physical system undergoes a regime change --- a material fractures, an epidemic tips from containment to exponential growth, or a manufacturing line hits capacity. The suite isolates this challenge in controlled settings where the true boundary geometry is known exactly.

### Phantom Function {#sec-data-phantom}

A bivariate response surface ($d = 2$) with a *sinusoidal jump boundary* at $\sin(x_1) = x_2$. Each regime generates the response from a different Gaussian component.

::: {.callout-note}
## Dataset summary
- *Source*: @flowers2026modular
- *Size*: $N = 10{,}201$ on a grid; $n_{\text{train}} \approx 9{,}000$ after 90/10 split
- *Dimension*: $d = 2$
- *Response*: Bimodal (two Gaussian components separated by jump)
- *Boundary*: $\sin(x_1) = x_2$ (sinusoidal)
- *Used in*: @sec-jumps-phantom (Aug-IQN benchmark)
:::

### Michalewicz Function {#sec-data-michalewicz}

The Michalewicz function [@surjanovic2013virtual] is a standard optimization test function with steep ridges and valleys:
$$
f(x) = -\sum_{i=1}^{d} \sin(x_i) \sin^{2m}\!\left(\frac{i \, x_i^2}{\pi}\right), \quad x_i \in [0, \pi],
$$ {#eq-michalewicz}
where $m = 10$ controls the steepness. In the Flowers suite, a $0.5$ offset is added to the flat region, introducing a jump manifold in four-dimensional input space.

::: {.callout-note}
## Dataset summary
- *Source*: @surjanovic2013virtual (Virtual Library of Simulation Experiments)
- *Size*: $N = 100{,}000$ (Latin hypercube sample), $d = 4$
- *Key feature*: Large $n$ makes MJGP computationally infeasible ($\geq 48$ hours)
- *Used in*: @sec-jumps (scalability demonstration)
:::

With $n = 90{,}000$ training points, the GP's $\mathcal{O}(n^3)$ cost is infeasible ($\approx 65$ GB for the covariance matrix alone). GBC trains in under 30 minutes on a single GPU, achieving CRPS = 0.031 with 91% coverage.


## BGP Test Functions {#sec-data-bgp}

The Bi-mixture Gaussian Process (BGP) test problems from @park2026active provide controlled *piecewise-continuous* response surfaces. A random hyperplane $a^\top x = 0$ partitions the unit hypercube into two regions, each with an independent GP realization at different mean levels:
$$
f_1 \sim \mathcal{GP}(13,\; 9\, k_{\text{SE}}), \quad f_2 \sim \mathcal{GP}(0,\; 9\, k_{\text{SE}}),
$$ {#eq-bgp-dgp}
with $k_{\text{SE}}$ using length scale $\ell = 0.1d$ and additive noise $\varepsilon \sim \mathcal{N}(0, 4)$.

::: {.callout-note}
## Dataset summary
- *Source*: @park2026active
- *Size*: $N = 2{,}000$ per realization, $d \in \{2, 3, 4\}$
- *Response*: Piecewise-continuous (two GP realizations with different means)
- *Partition*: Random hyperplane $a^\top x = 0$ with $a \in \{-1, +1\}^d$
- *Used in*: @sec-surr-bgp (GBC vs. stationary GP)
:::

```python
#| eval: true
#| code-fold: true
#| fig-cap: "One realization of the BGP test function in $d = 2$ with $a = (1, -1)$. The dashed line shows the partition boundary $a^\\top x = 0$ (i.e., $x_1 = x_2$). The two GP regimes have means 0 and 13, creating a visible jump."
#| label: fig-data-bgp
import numpy as np
import matplotlib.pyplot as plt
from scipy.linalg import cholesky

np.random.seed(7)
n = 800
d = 2
X = np.random.uniform(-0.5, 0.5, size=(n, d))

a = np.array([1.0, -1.0])
region = (X @ a >= 0).astype(int)

def se_kernel(X1, X2, sigma2=9.0, ls=0.2):
    diff = X1[:, np.newaxis, :] - X2[np.newaxis, :, :]
    sq_dist = np.sum(diff**2, axis=-1)
    return sigma2 * np.exp(-sq_dist / (2.0 * ls**2))

f = np.zeros(n)
for idx_set, mean_val in [(region == 1, 13.0), (region == 0, 0.0)]:
    idx = np.where(idx_set)[0]
    if len(idx) == 0:
        continue
    K = se_kernel(X[idx], X[idx]) + 1e-5 * np.eye(len(idx))
    L = cholesky(K, lower=True)
    f[idx] = L @ np.random.randn(len(idx)) + mean_val

y = f + np.random.normal(0, 2, n)

fig, ax = plt.subplots(1, 1, figsize=(5.5, 5))
sc = ax.scatter(X[:, 0], X[:, 1], c=y, s=8, alpha=0.6, cmap='RdYlBu_r',
                rasterized=True)
xb = np.linspace(-0.5, 0.5, 100)
ax.plot(xb, xb, 'k--', linewidth=1.5, label=r'$a^\top x = 0$')
ax.set_xlabel("$x_1$")
ax.set_ylabel("$x_2$")
ax.set_xlim(-0.55, 0.55)
ax.set_ylim(-0.55, 0.55)
ax.set_title("BGP realization ($d = 2$)")
ax.legend(fontsize=8)
ax.set_aspect('equal')
plt.colorbar(sc, ax=ax, label='Response', shrink=0.8)
plt.tight_layout()
plt.show()
```

GBC's CRPS advantage over the stationary GP grows from 11% at $d = 2$ to 26% at $d = 4$, because the GP's single global length scale becomes progressively less effective as more training data falls near the hyperplane boundary. Full results appear in @sec-surr-bgp.


## Friedman 10D {#sec-data-friedman}

The Friedman function [@friedman1991multivariate] is a standard benchmark for high-dimensional regression:
$$
f(x) = 10\sin(\pi x_1 x_2) + 20(x_3 - 0.5)^2 + 10 x_4 + 5 x_5, \quad x \in [0,1]^{10}.
$$ {#eq-friedman}

Only five of the ten inputs are active; the remaining five are inert noise variables. The $\sin(\pi x_1 x_2)$ term creates a non-separable interaction that separable GP kernels cannot represent faithfully.

::: {.callout-note}
## Dataset summary
- *Source*: @friedman1991multivariate
- *Size*: $n \in \{500, \ldots, 20{,}000\}$ (varies by experiment), $d = 10$
- *Active inputs*: Only $x_1, \ldots, x_5$; the remaining five are inert noise variables
- *Key features*: Nonlinear interaction ($\sin(\pi x_1 x_2)$), quadratic and linear terms, inert variables
- *Noise*: $\varepsilon \sim \mathcal{N}(0, 1)$
- *Used in*: @sec-surr-friedman (GBC vs. GP), @sec-surr-scaling (scaling study)
:::

### Rocket Booster (LGBB) {#sec-data-rocket}

The Langley Glide-Back Booster benchmark [@pamadi2004aerodynamic; @gramacy2020surrogates; @sauer2023active] models aerodynamics of a reusable NASA rocket booster. The three inputs are Mach number, angle of attack, and side-slip angle; the response is the side-force coefficient. A sharp nonlinear ridge at the sound barrier (Mach $\approx 1$) makes this hostile to stationary GPs.

::: {.callout-note}
## Dataset summary
- *Source*: @pamadi2004aerodynamic (NASA); used in @gramacy2020surrogates and @sauer2023active
- *Size*: $n_0 = 50$ initial points, growing to $n = 300$ via active learning
- *Dimension*: $d = 3$ (Mach number, angle of attack, side-slip angle)
- *Response*: Side-force coefficient
- *Key feature*: Sharp nonlinear ridge at the sound barrier (Mach $\approx 1$)
- *Used in*: @sec-al-rocket (active learning benchmark where GBC dominates)
:::

GBC-AL achieves $2.95\times$ lower RMSE than DGP+ALC --- the most dominant result in our active learning comparisons, with 90% confidence bands separating completely by $n \approx 150$.

### Satellite GRACE {#sec-data-satellite}

The Satellite GRACE benchmark [@sun2019emulating; @mehta2014modeling; @sauer2023active] uses a Test Particle Monte Carlo (TPMC) simulator to compute drag coefficients for satellites in low-Earth orbit. The seven inputs describe thermospheric conditions; the response is the satellite drag coefficient. The surface is smooth and well-matched to GP assumptions.

::: {.callout-note}
## Dataset summary
- *Source*: @sun2019emulating; TPMC simulator for GRACE satellite
- *Size*: $n_0 = 110$ initial points (including replicate pairs), growing to $n = 500$
- *Dimension*: $d = 7$ (atmospheric composition, velocity, temperature variables)
- *Response*: Satellite drag coefficient
- *Key feature*: Smooth surface, stochastic simulator (~86 seconds per evaluation)
- *Used in*: @sec-al-satellite (active learning crossover benchmark)
:::

This dataset reveals a *crossover*: GBC-AL leads in the early acquisition phase ($n < 300$) but the GP-based DGP+ALC overtakes GBC at larger sample sizes ($n = 500$). The lesson: when the total acquisition budget is small (the practically relevant regime for expensive simulators), GBC provides better accuracy; when the budget is large and the surface is smooth, the GP's inductive bias eventually wins.


## Ebola Agent-Based Model {#sec-data-ebola}

The Ebola agent-based model [@fadikar2018calibrating] simulates disease spread through a population, producing 56-week epidemic trajectories as output. Five input parameters control transmission rate, initial infections, hospital intervention timing and efficacy, and travel reduction. The ABM has no tractable likelihood --- the stochastic, agent-level interactions are far too complex for any analytical likelihood function --- making it a canonical example for likelihood-free Bayesian inference.

::: {.callout-note}
## Dataset summary
- *Source*: @fadikar2018calibrating; RAPIDD Ebola Forecasting Challenge [@viboud2018rapidd]
- *Size*: 300 parameter scenarios, 100 replicates each, 56-week trajectories
- *Dimension*: $d = 5$ input parameters
- *Response*: 56-week cumulative incidence trajectory
- *Key feature*: Bimodal output (epidemic vs. no epidemic), no tractable likelihood
- *Used in*: @sec-bayesian-inference (posterior inference for simulator parameters)
:::

The ABM exhibits *bimodal behavior*: for some parameter settings the epidemic takes off; for nearby settings it sputters and dies. This tipping-point structure produces a bimodal output distribution that no Gaussian surrogate can represent faithfully. We use GBC to learn the posterior quantile function and produce credible intervals for all five parameters, including in the bimodal regime. Details in @sec-bayesian-inference.


## Lake Temperature {#sec-data-lake}

The Falling Creek Reservoir lake temperature dataset [@holthuijzen2025synthesizing] consists of $N = 281{,}764$ records combining physics-based General Lake Model (GLM) outputs with observed water temperatures at multiple depths and forecast horizons. Six input features include day of year, depth, forecast horizon, lagged surface temperature, and the GLM ensemble mean and standard deviation.

::: {.callout-note}
## Dataset summary
- *Source*: @holthuijzen2025synthesizing; Falling Creek Reservoir, Virginia
- *Size*: $N = 281{,}764$ ($n_{\text{train}} = 172{,}714$, $n_{\text{test}} = 109{,}050$)
- *Dimension*: $d = 6$ input features
- *Response*: Observed water temperature (${}^\circ$C)
- *Key feature*: High signal-to-noise ratio causes IQN failure
- *Train/test split*: Temporal (before / after 2022-06-11)
- *Used in*: @sec-calibration (het-MLP ensemble + conformal calibration)
:::

This dataset illustrates a case where the IQN *fails*: the high signal-to-noise ratio (the physics-based simulator already captures most of the variance) causes the multiplicative $\tau$-embedding architecture to collapse all quantile levels to the conditional mean. The failure motivates the het-MLP ensemble with conformal calibration developed in @sec-calibration.


## LaLonde Wage Data {#sec-data-lalonde}

The LaLonde dataset [@lalonde1986evaluating] evaluates the effect of the National Supported Work (NSW) job training program --- a randomized experiment with known average treatment effect (ATE $\approx$ \$1,500--\$2,000 in 1978 dollars), providing rare ground truth for causal inference methods.

::: {.callout-note}
## Dataset summary
- *Source*: @lalonde1986evaluating; refined by @dehejia1999causal
- *Size*: $n = 445$ (185 treated, 260 control)
- *Dimension*: $d = 8$ covariates
- *Treatment*: NSW job training program (binary)
- *Response*: Real earnings in 1978 (dollars)
- *Key feature*: Randomized experiment with known ATE $\approx$ \$1,500--\$2,000
- *Used in*: @sec-causal-lalonde (causal inference benchmark)
:::

GBC estimates not only the ATE but the *quantile treatment effect* (QTE) --- how the treatment reshapes the entire outcome distribution. On the LaLonde data, the QTE profile reveals that the NSW program's primary benefit is preventing the worst outcomes, with large effects at low quantiles and smaller effects at higher quantiles. We develop this approach in @sec-causal-lalonde.
