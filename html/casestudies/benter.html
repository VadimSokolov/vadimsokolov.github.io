Benter’s Betting Strategy

Author

Vadim Sokolov

Published

This chapter reproduces the analysis from Bill Benter’s seminal paper on computer-based horse race handicapping (Benter 2008), as annotated and extended by Acta Machina.

Bill Benter is perhaps the most successful professional gambler in history, having reportedly accumulated over $1 billion betting on horse races in Hong Kong. In 1994, he published an academic paper documenting the principles behind his betting system, which remains a cornerstone reference for quantitative sports betting.

The key insight from Benter’s work is that the public betting odds contain valuable information about horse performance, but this information is systematically biased. By combining the public’s probability estimates with a fundamental handicapping model, one can achieve a significant edge over the market.

One of the most well-documented phenomena in horse racing is the favorite-longshot bias: favorites tend to win more often than the odds suggest, while longshots win less often. This creates a predictable miscalibration in the betting market.

Data

We use historical race data from the Hong Kong Jockey Club. The raw data comes from the gdaley/hkracing Kaggle dataset, which contains detailed race results from 1997-2005 including approximately 6,300 races and 79,000 individual horse performances.

The raw Kaggle data consists of two tables:

  • races.csv: race-level information (date, venue, distance, track conditions)
  • runs.csv: horse-level results (finishing position, odds, jockey, trainer, weight, rating)

We process these into a single analysis-ready dataset using the script code/prepare_hkjc_data.py:

The key preprocessing step is computing historical statistics that avoid lookahead bias. For each horse in each race, we calculate the jockey’s and trainer’s win rate using only races that occurred before the current race:

\[ \text{WinRate}_{j,t} = \frac{\sum_{s < t} \mathbf{1}[\text{jockey } j \text{ won race } s]}{\sum_{s < t} \mathbf{1}[\text{jockey } j \text{ rode in race } s]} \]

We skip the first 180 days of data to ensure sufficient history for reliable statistics. We start by loading the data.

The Calibration Problem

If the betting market were perfectly efficient, the implied probability \(p_i\) would equal the true probability \(\pi_i\) that horse \(i\) wins. We test this by dividing all horses into 20 equal-sized groups (ventiles) based on their public probability, then calculating the mean predicted probability and actual win rate within each group. For each bin, we compute the calibration error as the difference between the observed win frequency and the average implied probability. Perfect calibration would produce errors near zero across all bins, with points falling along the 45-degree line where predicted probabilities match actual outcomes.

The Combined Model

Benter’s key contribution was the combined model, which adjusts the public probability estimates using a conditional logit framework. The model computes adjusted probabilities as:

\[ c_i = \frac{\exp(\alpha f_i + \beta \pi_i)}{\sum_{j=1}^{N} \exp(\alpha f_j + \beta \pi_j)} \]

where \(f_i\) represents fundamental factors (jockey, trainer, weight, etc.) and \(\pi_i = \text{logit}(p_i)\) is the log-odds of the public probability. Crucially, the public estimate \(\pi_i\) serves as the key regressor: all predictions are made relative to market perception rather than from scratch, leveraging the crowd’s aggregated information while correcting for systematic biases.

Since we lack fundamental factors in this dataset, we fit a simplified version using only the public estimate:

\[ c_i = \frac{\exp(\alpha \cdot \text{logit}(p_i))}{\sum_{j=1}^{N} \exp(\alpha \cdot \text{logit}(p_j))} \]

When \(\alpha > 1\), the model amplifies the differences between favorites and longshots, correcting for the favorite-longshot bias. When \(\alpha = 1\), we recover the original public probabilities.

We find the optimal \(\alpha\) by maximum likelihood:

\[ \mathcal{L} = -\sum_{\text{races}} \log c_{\text{winner}} \]

# Prepare race-level data
race_ids <- unique(df$race_id)
race_data <- lapply(race_ids, function(rid) {
  df |> filter(race_id == rid)
})

# Logit function
logit <- function(p) {
  p <- pmax(pmin(p, 1 - 1e-10), 1e-10)
  log(p / (1 - p))
}

# Objective function for combined model
objective <- function(alpha) {
  total_nll <- 0
  for (race in race_data) {
    if (nrow(race) < 2) next
    z <- logit(race$public_prob)
    Z <- alpha * z
    Z <- Z - max(Z)  # numerical stability
    c_prob <- exp(Z) / sum(exp(Z))
    winner_idx <- which(race$win == 1)
    if (length(winner_idx) == 1) {
      total_nll <- total_nll - log(max(c_prob[winner_idx], 1e-10))
    }
  }
  return(total_nll)
}

result <- optimize(objective, interval = c(0.3, 2.0), tol = 0.001)
alpha <- result$minimum

cat(sprintf("Optimal alpha: %.3f\n", alpha))
Optimal alpha: 1.062

The optimal parameter is \(\alpha = 1.06\), confirming that the market systematically underbets favorites. With \(\alpha > 1\), the model shifts probability mass from longshots to favorites.

Model Performance

We evaluate the adjustment using the Brier score, which measures the mean squared error between predicted probabilities and actual outcomes. For each horse in each race, we calculate \((p_i - y_i)^2\), where \(p_i\) is the predicted probability and \(y_i\) is the actual outcome (1 if the horse won, 0 otherwise). The Brier score is the average of these squared errors across all horses in the dataset. A lower Brier score indicates better calibration between predicted probabilities and observed outcomes. We compute this metric both before adjustment (using raw public probabilities) and after adjustment (using the \(\alpha\)-corrected probabilities), allowing us to quantify the improvement from our model.

The Full Combined Model

Benter’s complete model incorporates fundamental factors beyond the public estimate:

\[ c_i = \frac{\exp(\alpha \cdot \text{logit}(p_i) + \sum_j \beta_j X_{ij})}{\sum_{k=1}^{N} \exp(\alpha \cdot \text{logit}(p_k) + \sum_j \beta_j X_{kj})} \]

We fit this model using our fundamental factors: jockey win rate, trainer win rate, draw position, and horse rating.

# Objective function for full combined model
obj_full <- function(params) {
  alpha <- params[1]
  beta_jockey <- params[2]
  beta_trainer <- params[3]
  beta_draw <- params[4]
  beta_rating <- params[5]
  
  total_nll <- 0
  for (race in race_data) {
    if (nrow(race) < 2) next
    z <- logit(race$public_prob)
    Z <- alpha * z + 
         beta_jockey * race$jockey_win_rate + 
         beta_trainer * race$trainer_win_rate +
         beta_draw * race$draw_normalized +
         beta_rating * race$rating_diff / 10
    Z <- Z - max(Z)
    prob <- exp(Z) / sum(exp(Z))
    winner <- which(race$win == 1)
    if (length(winner) == 1) {
      total_nll <- total_nll - log(max(prob[winner], 1e-10))
    }
  }
  total_nll
}

# Fit the full model
full_result <- optim(c(1, 0, 0, 0, 0), obj_full, method = "L-BFGS-B",
                     lower = c(0.5, -10, -10, -5, -5), 
                     upper = c(2, 10, 10, 5, 5))

The model comparison table evaluates three progressively sophisticated approaches to predicting race outcomes. The raw public odds serve as our baseline, representing the collective wisdom of the betting market without any adjustments. The public adjusted model applies only the \(\alpha\) correction to address the favorite-longshot bias, transforming public probabilities through \(\alpha \cdot \text{logit}(p_{\text{public}})\) before renormalizing. The full combined model incorporates all fundamental factors—jockey performance, trainer success, post position, and horse rating—on top of the adjusted public estimate.

We measure predictive accuracy using the Brier score, which quantifies the mean squared error between predicted probabilities and actual outcomes: \(\text{Brier} = \frac{1}{N}\sum_{i=1}^N (p_i - y_i)^2\), where \(p_i\) is the predicted probability and \(y_i \in \{0,1\}\) indicates whether horse \(i\) won. Lower scores indicate better calibration. The improvement percentages show how much each refinement reduces prediction error relative to the baseline.

To test whether the additional complexity of the full model is statistically justified, we perform a likelihood ratio test comparing the public-adjusted model (nested within the full model) against the full specification. The test statistic \(\text{LR} = 2(\ell_{\text{full}} - \ell_{\text{public}})\) follows a \(\chi^2\) distribution with degrees of freedom equal to the number of additional parameters (four: jockey, trainer, draw, and rating coefficients). A significant p-value indicates that the fundamental factors provide genuine predictive power beyond what the public odds already capture.

Betting Strategy

Given a model with positive expected value, the Kelly criterion provides the optimal bet sizing:

\[ f^* = \frac{bp - q}{b} \]

where \(b\) is the decimal odds minus 1, \(p\) is the model’s win probability, and \(q = 1 - p\). In practice, bettors use a fraction of Kelly (typically 25-50%) to reduce variance and protect against model error.

Price Impact and Adjusted Kelly

At Benter’s scale, bet sizes were large enough to move the odds. In pari-mutuel betting, placing a large bet on a horse reduces its payout for everyone, including yourself. This creates a feedback loop: the optimal bet depends on the final odds, but the final odds depend on your bet.

Benter addressed this by solving for the bet size that maximizes expected log-wealth after accounting for the price impact. The adjusted Kelly formula becomes implicit: you must find the bet \(b^*\) such that:

\[ b^* = f^*(\text{odds after bet } b^*) \]

This typically results in smaller bets than naive Kelly would suggest, as large bets erode their own edge.

Profit Targeting

Rather than maximizing growth rate (which Kelly optimizes), Benter reportedly targeted a flat expected profit of approximately $10,000 per race meeting. This conservative approach prioritizes consistent returns over aggressive compounding, reducing the psychological burden of high-variance outcomes and providing a sustainable business model.

Multiple Bets and the Water-Filling Solution

A key insight is that betting on multiple horses in the same race can be optimal, even though at most one can win. The mathematical framework is analogous to the water-filling algorithm in information theory, where you allocate resources across channels proportional to their capacity.

For horse racing, you bet on all horses where your estimated probability exceeds the implied probability by enough to overcome the track take. The optimal allocation solves:

\[ \max \sum_i w_i \log(1 + b_i \cdot \text{odds}_i) + (1 - \sum_i w_i) \log(1 - \sum_i b_i) \]

where \(w_i\) is your model’s probability that horse \(i\) wins.

This diversification is particularly valuable because bets on different horses have negative correlation: if horse A wins, horse B loses. Unlike most financial portfolios where assets can rise together, horse race bets provide natural hedging. This is the ensemble variance decomposition in action: when combining \(n\) bets with variance \(\sigma^2\) and pairwise correlation \(\rho\), the portfolio variance is \(\sigma^2[(1-\rho)/n + \rho]\). With positive correlation (\(\rho > 0\)), diversification helps but hits a floor; with negative correlation (\(\rho < 0\)), variance can be driven far below the individual bet variance. The same principle applies in trading strategies with mean-reverting pairs or market-neutral portfolios, where diversification across negatively correlated positions dramatically reduces variance while preserving expected returns.

Synthetic Bets via Exacta Pools

An important insight from Benter’s operation is that win bets can be constructed synthetically from exacta pools. An exacta bet pays if you correctly predict both the first and second place finishers. If you bet on all exactas with horse A in first place (A-1, A-2, A-3, …, A-N for all other horses), you are effectively betting that A wins regardless of who finishes second. The payout is the probability-weighted average of the exacta payouts.

This synthetic construction matters because the exacta pool is often less efficient than the win pool, particularly for longshots or in races with unusual configurations. The arbitrage relationship should hold: \[ \text{Win odds for A} \approx \frac{1}{\sum_{j \neq A} \frac{1}{\text{Exacta odds}_{A,j}}} \] When this relationship breaks down, Benter’s syndicate could exploit the discrepancy by betting in whichever pool offered better value. More generally, exotic bet pools (exactas, trifectas, quinellas) provide additional degrees of freedom for expressing views and harvesting mispricings that sophisticated bettors can exploit.

Conclusion

Our analysis of Hong Kong Jockey Club data confirms the findings from Benter’s original paper:

  • The betting public systematically underbets favorites and overbets longshots (the favorite-longshot bias)
  • The optimal adjustment parameter \(\alpha = 1.06\) corrects this bias
  • Fundamental factors (jockey, trainer, draw, rating) provide additional predictive power beyond public odds
  • The full combined model significantly outperforms the public-only model (p < 0.05)

The key lessons from Benter’s work remain relevant today:

  • High-quality historical data is essential for building predictive models
  • Market prices contain valuable information but exhibit systematic biases
  • Simple adjustments can improve on public estimates
  • The combination of public estimates with fundamental factors yields the best results
  • Disciplined bet sizing using Kelly or fractional Kelly is critical for long-term success

While the specific edge has likely diminished since the 1990s due to increased competition from sophisticated bettors and syndicates, the methodology remains a template for quantitative sports betting and prediction markets more broadly.

Connection to Quantitative Finance

Benter’s approach shares deep connections with the broader quantitative finance literature pioneered by Edward Thorp. In his comprehensive review of the Kelly criterion (Thorp 2003), Thorp traces the mathematical foundations from Shannon’s information theory through practical applications in blackjack, sports betting, and securities markets. The core insight, that maximizing expected logarithmic utility leads to optimal long-term growth, unifies Benter’s horse racing strategy with modern portfolio theory.

For the mathematical derivation of the Kelly criterion and its connection to utility theory, see the discussion in the Utility, Risk and Decisions chapter (specifically the Kelly Criterion example). The fundamental result, derived from maximizing expected log-wealth, is that for a bet with win probability \(p\) and loss probability \(q = 1-p\), the optimal fraction of capital to wager is \(\omega^* = p - q\). With asymmetric payouts \((a, b)\) where you lose \(a\) on a loss and gain \(b\) on a win, this generalizes to: \[ \omega^* = \frac{bp - aq}{ab} \] In betting markets with decimal odds \(O\), this becomes \(\omega^* = (pO - q)/O\). The Kelly criterion can recommend very different bet sizes for opportunities with identical expected returns but different odds structures, favoring lower-odds propositions where the edge is more certain. For instance, a bet at 4/1 odds with your estimated probability of 1/4 and a bet at 12/1 odds with your estimated probability of 1/10 both offer identical 33% expected returns, yet Kelly advises allocating twice as much capital to the lower-odds bet (1/16 vs 1/40 of bankroll).

Thorp’s practical wisdom, documented extensively in interviews and articles (Barrow 2017), provides guidance that Benter clearly applied:

  • Fractional Kelly: Thorp recommends betting around half-Kelly because “you get about three-quarters of the return with half the volatility.” Since true win rates and edges are never known with certainty in markets, conservative sizing protects against estimation error. When developing new strategies with uncertain edges, Thorp was even more conservative, simulating at just 1/10 of the Kelly number.

  • Drawdown management: Thorp suggests reducing position size during losing streaks: “If we lost 5 percent, we would shrink our positions. If we lost another few percent, we would shrink our positions more.” The system would gradually shut itself down as drawdowns deepened, then “had to earn its way out.” This prevents catastrophic losses and ensures survival through adverse periods.

  • Correlation matrix: Thorp’s team tracked correlations systematically: “We tracked a correlation matrix that was used to reduce exposures in correlated markets. If two markets were highly correlated, and the technical system went long one and short the other, that was great. But if it wanted to go long both or short both, we would take a smaller position in each.” He found a 60-day lookback optimal; shorter windows are too noisy, longer ones produce stale correlations. In horse racing, this manifests as spreading bets across races and bet types rather than concentrating on a single outcome.

  • Worst-case thinking: “Assume that the worst imaginable outcome will occur and ask whether you can tolerate it. If the answer is no, then reduce your borrowing.”

  • Exploiting dislocations: During the 1987 crash, while others panicked, Thorp calmly identified that S&P futures were trading at 185-190 while the index itself was at 220, a 30-35 point spread that was previously unheard of. He exploited this by going long futures and shorting stocks, locking in a guaranteed profit when the spread converged. The lesson: extreme market stress creates mispricings that disciplined quantitative traders can harvest.

These principles enabled Thorp’s Princeton Newport Partners to compound at 19.1% annually for nearly 20 years without a single down year. Benter’s reported billion-dollar fortune stands as perhaps the most striking validation of these same principles applied to a real-world betting market, demonstrating that disciplined application of Kelly-based position sizing can convert even modest edges into extraordinary long-term wealth.
