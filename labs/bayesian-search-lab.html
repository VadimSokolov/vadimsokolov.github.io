Bayesian Search Lab

A lost submarine lies somewhere on a 15 × 15 grid. The map starts as a prior built from three weighted scenarios. Each failed search lowers the probability of the searched cell and raises every other cell. Hunt by hand, then compare two search rules over many simulated hunts.

John Craven and the USS Scorpion, 1968

Prior belief + facts = revised belief

Craven had experts bet on what had happened to the Scorpion, turned the scenarios into a probability map, and searched where the map pointed. This lab follows his four steps on a made-up grid. The scenarios, trench and detection rates are simulated for teaching and are not the real Scorpion search data.

  1. Prior map

    Combine expert scenarios into P(location) for every cell, and record how likely a search is to spot the wreck if it is there (q). Deep water makes q small.

  2. Search the highest-probability cell

    The simple rule: search the cell with the largest p, for example C5. A refinement uses p × q, the chance that this search succeeds.

  3. Update after a failed search

    Nothing found is evidence. The searched cell keeps only the part of its probability where the search missed, p(1 − q), and every cell is rescaled by 1 − p·q so the map sums to 1 again. Other cells rise.

  4. Iterate

    Repeat steps 2 and 3 until you find the target. A cell with low q gets searched again and again, because one miss there says little.

Bayes' rule
P(loc | evidence) = P(evidence | loc)·P(loc) / P(evidence)
Searched cell i, nothing found
P(no find) = 1 − pi·qi
pi ← pi(1 − qi) / (1 − piqi)
Every other cell j
pj ← pj / (1 − piqi)

Takeaway for students. A failed search is not wasted. It moves probability to the cells you have not checked. The same update finds lost aircraft (Air France 447) and, run millions of times a second, tells a self-driving car where it is (SLAM).

Try this in class

  1. Before any search, ask students to name the cell they would search first. Then switch the map between "Posterior p", "Detection q" and "p × q" and ask whether they would change their answer.
  2. Press "Search best cell" five times and watch the searched cell fade while scenario B's area darkens. Read "Its p before → after" and check it against p(1 − q) / (1 − pq).
  3. Click a cell far from every scenario and search it. Its p barely changes, and neither does the rest of the map. Ask why a search there tells you so little.
  4. Run the comparison. Then press "Same detection everywhere" and run it again. When q is the same in every cell, the two rules pick the same cells and tie.
  5. Set scenario A's weight to 0 and start a new hunt. Ask what the experts' bet would cost if the wreck really was near A, then tick "Show the true location".
